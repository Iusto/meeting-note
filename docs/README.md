## 문서 관리 기준

| 내용 | 기록 위치 |
|---|---|
| 구현 상태·남은 작업 | 08 개발 계획 |
| 실행 일시·조건·결과·한계 | 07 테스트·검증 |
| 채택·변경·보류한 결정과 이유 | 10 기술 결정 |
| 결정에 이른 대화 배경 | HISTORY |
| 변경 사항 요약 | CHANGELOG |

같은 실행 일지와 테스트 숫자를 여러 문서에 반복하지 않는다. 성능 목표를 달성 수치로 표현하지 않으며, 과거 검증과 이번 변경의 검증을 구분한다. 별도 완료 보고서·빈 실험 양식을 늘리지 않는다. 파일 번호와 경로는 기존 참조를 위해 유지한다.

현재 규격은 최신 사용자 지시와 [개발 지침](../AGENTS.md), 채택된 기술 결정·요구사항을 따른다. 과거 논의는 현재 구현 상태의 근거로 사용하지 않는다.
