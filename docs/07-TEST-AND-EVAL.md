남은 검증은 실제 디스크 포화/절전·변경 이미지 재배포와 외부 공급자 품질이다. 실비 POC는 별도 승인 전 실행하지 않는다.

추가 통합 시험은 API 키를 사용하지 않았다. 다화자 final의 두 번째 DB 삽입을 실패시켜 전체 발언과 speaker가 롤백되는지 H2·실제 PostgreSQL에서 확인했다. final 이후 늦은 partial, 전사/승인 용어 변경 중 AI 지연 응답, 거절된 응답·잘못된 usage·예약 초과·무응답·호출자 취소도 포함했다. 서버 로그는 `.tools/ai-integration-full.log`에 있다. 웹 15개와 lint·타입 검사·빌드도 재통과했다.

독립 구조 리뷰는 WATCH다. 운영 연결 전 활성 세션 단일화·재연결 중복 방지, cleanup 예외 시 원장/세션의 독립적인 종료 시도, 공급자 요청 ID 기록이 필요하다. 코드 리뷰의 중간 지적(다화자 부분 저장·final 후 partial)은 수정하고 회귀 시험을 통과했다. 5시간 사용량 94%에서 새 작업과 남은 리뷰를 중단했으며 코드 리뷰 최종 판정은 미수신이다. 두 독립 리뷰가 모두 끝나지 않았으므로 전체 리뷰 승인·전체 서비스 완료·운영 활성화 승인으로 해석하지 않는다.

사용자가 휴대폰의 Tailscale HTTPS 로그인과 실제 녹음 파일 재생을 확인했다. `.bin` 다운로드는 서버 응답의 고정 파일명 문제로 확인해 녹음 MIME에 맞게 `.webm`/`.ogg`로 수정했다. 저장 파일·인코딩은 변경하지 않았다. 추가 매개변수 시험의 로그인 제한 충돌은 테스트 준비에서 기존 SessionService를 사용해 해결했고, 파일 시험의 임시 경로는 Surefire `argLine`으로 작업 폴더를 지정했다. 유료 호출은 없으며 운영 반영은 남아 있다.

첫 4시간 시험은 지속시간 검사에 실패했다(14,396,090ms, 기준 14,398,000ms). 청크 단절 없이 해시·별도 재생은 확인했으나 전체 통과로 계산하지 않았다. 테스트의 Node 벽시계와 브라우저 단조 시계 혼용을 수정하고 타입 검사·재시작·1분 시험을 통과한 뒤, 19일 00:30~04:30 KST의 4시간 재시험이 통과했다. 브라우저 경과 14,400,019.3ms, 기록 길이 14,400,058ms이며 기존 2초 허용치는 유지했다. 실패/통과 보고서와 녹음은 로컬 증거로 보존하고 소유 임시 DB·프로세스는 정리했다.

## 테스트 계층
- 백엔드: JUnit 5, Spring Boot Test, 기본 H2와 선택 실행하는 실제 PostgreSQL 임시 DB, WebSocket/HTTP 가짜 공급자. PostgreSQL 시험 계정에는 임시 DB 생성 권한이 필요하다.
- 프론트: Vitest + React Testing Library; 최소 주요 UX E2E는 Playwright.
- 외부 API: 키 없는 Mock/녹음 fixture로 기본 테스트. **명시적 예산 opt-in**인 별도 POC만 실비 호출.

## 품질 게이트 1 — Nova-3 POC (Phase 1)
동일한 **가상** 한국어 MES 샘플(2~4인, 5~15분; 단일 마이크, 말 겹침, 키워드 변형)로 측정한다.
| 지표 | 측정법/판단 |
|---|---|
| 실시간성 | 첫 자막 지연 p50/p95, 발언 종료→final 지연, 실시간 누락 |
| 한국어 CER/WER | 사람이 교정한 참조 전사본과 비교; 규칙 통일 |
| 전문용어 | LOT/BOM/WIP recall/precision, keyterm ON/OFF 비교 |
| 화자 구분 | DER 또는 화자 전환 오류 건수, overlap별 별도 기록 |
| 원문 보존 | final·녹음 fragment 누락 0건 목표, 중복 이벤트 멱등 |
| 비용 | 실 청구 오디오 분수 / 추가 옵션 분당 단가 / 세션 재연결 누적 |

**POC를 통과하지 못하면** Deepgram 채택 확정 금지. 같은 오디오로 AssemblyAI 또는 다른 STT 후보와 비교하고 ADR 수정. 특定 사업자의 광고 벤치마크를 한국어 품질의 증거로 삼지 않는다.

실험 결과는 실행 후 이 문서에 기록한다. 일시·입력 환경·마이크/코덱·오디오 길이/화자 수·모델/파라미터/라이브러리·relay 버전·지역/네트워크/브라우저, 각 지표의 기준·측정값·판정, 오류 구간의 실제 발언/API 결과/조치, GO/NO-GO와 이유·후속 ADR을 남긴다. 실행 전 값은 미측정이며 추정 성능을 채우지 않는다.

## 품질 게이트 2 — 실사용 스트레스 (Phase 4)
- 15분 → 60분 → **4시간** 연속 녹음·전사·다중 세션 재연결.
- 연결 끊김/브라우저 refresh/절전/서버 프로세스 재기동/디스크 부족을 각각 테스트.
- `PARTIAL` 이벤트가 역전·중복·누락되어도 확정 데이터가 오염되지 않는지 확인.
- 말더듬, 발언 정정, 사전 미등재 전문용어, 중요 LOT ID 오독, 비슷한 화자 목소리, 동시 발언.

## 목표(실측 성능 보장 아님)
- 첫 자막 지연 p95 ≤ 3초를 첫 목표로 두되 실측 실패 시 UI/모델/네트워크 최적화 또는 목표 재설정.
- 4시간 원음 저장 누락 0건; 불가 시 실패 범위 명시하고 개선 전까지 실사용 금지.
- 한국어 정확도와 화자 성능의 POC 합격선은 기준 샘플을 만든 후 **사용자와 결정**.

## 평가 데이터 취급
실제 회사 회의 음성은 사내 정책과 참가자 동의 확인 전 클라우드 API에 전송하지 않는다. 평가용 자료는 합성 음성/동의된 녹음만 사용하고 Git에 개인 음성을 커밋하지 않는다.
