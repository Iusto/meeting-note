# 08. 개발 계획과 구현 상태

최신 추가(2026-11-04): 같은 회의에 접속한 기기의 기본 실시간 보기를 구현했다(ADR-026). 휴대폰에서 마이크를 시작하고 노트북에서는 같은 회의를 열면 자동으로 발언을 받는다. 화자 수정·수동 교정 공유, 재접속 후 저장 전사 복구, 원격 명시적 종료 시 녹음 마무리를 포함한다. 보기만으로 STT를 추가 실행하지 않는다. 실제 휴대폰 장시간·절전 검증과 한국어 전사/화자 품질 비교는 남아 있다. 최신 검증·배포 결과는 07의 같은 날짜 실시간 보기 항목을 따른다.

동일 변경의 API·웹·브라우저 회귀 통과 후 운영 Docker api/web에 반영했다. health UP과 Tailscale HTTPS 웹 200을 확인했으며 별도 `start-meeting.bat` 재실행 없이 새 화면을 사용할 수 있다. 기존에 열어둔 기기 화면은 새로고침해야 한다.

기준일: 2026-11-04. 각 구현 범위는 관련 테스트를 통과한 뒤 다음 작업으로 진행한다. 실행 결과와 한계는 [07 테스트·검증](07-TEST-AND-EVAL.md)에 기록한다. 이전 OpenAI 요약 오류의 진단 경위는 07과 HISTORY에 남기며, 현재 기본 요약 경로는 Codex 구독이다.

## 현재 상태

회의록은 등장 순서의 `화자 1`, `화자 2`를 표시하고 이름 지정·합치기/분리·발언별 화자 수정을 지원한다. 긴 전사의 내부 스크롤·고정 요약 사이드바와 기본 실시간 보기를 운영 이미지에 반영했다. 사용자는 첫 실회의에서 전사 내용과 화자 구분의 문제를 보고했고, 요약은 나름 괜찮았다고 평가했다. 이는 정량 품질 측정과 구분한다.

| 구분 | 상태 |

| 구현·검증 | 단일 소유자 로그인, 회의 관리, 녹음·복구, 사전·교정·구조화 요약, 화자 이름/연결/개별 수정, 검색·내보내기, 기본 실시간 보기, 원장·예산 제어, 삭제·백업/복원 |

일반 Compose의 기본 실행은 외부 AI 호출이 꺼져 있다. `start-meeting.bat` 또는 `start-private.ps1 -EnablePaidAi`는 기본 Codex 구독 경로와 Deepgram LIVE를 연결하며, 전사는 양수의 월 예산·회의 상한을 확인한다. Codex 요약은 API 달러 예산 대신 구독 한도를 사용한다. OpenAI API 경로는 `-UseOpenAiApi`로 명시적으로 선택한다.

## 다음 작업 — 휴대폰 녹음과 전사 품질 확인

2026-10-25 사용자 요청으로 **별도 유료 POC를 먼저 수행하는 순서에서, 실제 웹앱에 연결하고 같은 경로로 통합 검증하는 순서로 변경**했다(ADR-021). 개인 사용 중 드러난 품질 문제는 반복 개선한다. 기존 독립 POC 명령은 선택적 진단 도구로 남기며 필수 선행 단계로 사용하지 않는다.

1. **사용자 기기 확인:** 양쪽에서 같은 회의를 열고 휴대폰에서만 마이크를 시작해 노트북의 실시간 보기·화자 수정 공유를 확인한다. 휴대폰 장시간·잠금/절전은 별도로 점검한다.
2. **품질 원인 분리:** 승인된 짧은 동일 발화로 마이크 입력과 저장 원본의 명료도, 전사 오류, 화자 분리를 구분해 비교한다. 다른 유료 STT 비교는 사용자 선택과 예산 확인 후 진행하며 자동 실행하지 않는다.
3. **결과 반영:** 실제 품질·누락·비용과 사용 조건은 07에 기록하고, 확인된 문제에 맞춰 구현·설계 문서·마스터 이력서를 갱신한다.

소스 연결 완료와 실제 공급자 품질·운영 배포 완료를 구분한다. 자동 테스트 통과만으로 한국어 인식률·화자·지연·청구액을 주장하지 않는다.

- 요약·교정·용어 후보의 전송을 Windows Codex bridge로 선택 가능하게 구현. `start-private.ps1 -EnablePaidAi`의 기본값은 Codex이며 API 키를 비움. `-UseOpenAiApi`로만 API 방식 선택.
