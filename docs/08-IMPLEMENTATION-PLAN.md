# 08. Codex CLI 개발 실행 계획 (개인용 / 실시간 우선)

> 각 구현 범위는 테스트를 통과한 뒤 진행한다. 실제 공급자 POC는 명시적인 유료 호출 승인과 시간·금액 상한이 필요하다.

2026-10-16 사용자 요청에 따라 Phase 1 실측을 보류하고 공급자 독립 기능을 선행했다. 현재 앱은 MOCK/LOCAL_RECORDING이며 실제 STT 품질 게이트는 미통과다. 실행 결과는 [테스트·검증](07-TEST-AND-EVAL.md)을 참고한다.

## 현재 상태와 다음 순서

| 범위 | 상태 |
|---|---|
| 구현·검증 | 인증·회의 관리·로컬 녹음/복구·사전/교정 검토·가상 요약·검색/내보내기·비용 원장/예산 차단·삭제·백업/복원 |
| 연결 준비 | Deepgram loopback 전사·원장 통합, OpenAI 주입 transport의 교정·요약·원장 통합, 별도 실행 POC 명령. 운영 앱에서는 미활성 |
| 남은 구현 | POC GO 이후 브라우저 오디오 relay·실제 공급자 활성화·재연결·긴 회의 분할 처리·실제 AI 사전 후보 |
| 남은 검증 | 실제 한국어 품질·지연·비용·STT WSS, 실제 디스크 포화/절전. 휴대폰 로그인·녹음 재생은 사용자 확인 |

2026-10-18~19 비용 예약·정산·청구 미확정 보존과 PostgreSQL 동시 예산 차단, 브라우저 저장 실패·서버 파일 쓰기 실패·API 강제 재시작 복구와 합성 마이크 60분·4시간 저장/재생을 검증했다. 다음은 시간·금액 상한을 정한 실제 한국어 POC이며, 유료 호출은 별도 승인 전 실행하지 않는다. 아래 Phase 체크 항목은 전체 수용 기준으로 유지한다.

오프라인 품질 평가기와 명시적 단가의 월 36/48/60시간 비용 계산기를 추가했다. 15개 도구 테스트를 통과했으며, 실제 POC 결과를 대신하지 않는다. 첫 4시간 시험의 지속시간 검사 실패 후 테스트의 시계 혼용을 수정했다. 짧은 검증을 거쳐 2026-10-19 04:30 KST에 4시간 재시험이 통과했으며 앱 코드는 변경하지 않았다.

2026-10-19 일반 Windows PowerShell용 [배포 스크립트](../scripts/README.md#windows-private-deployment)의 가짜 명령 테스트 7개 통과 후, 사용자 로그에서 이미지 빌드와 DB/API/web Healthy를 확인했다. Serve 활성화 후 배포 PC에서 로컬 HTTP·Tailscale HTTPS 루트 200과 미인증 API 401을 직접 확인했다. 에이전트의 제어 named pipe 제한은 유지되며 실제 공급자의 WSS 검증은 남아 있다.

이후 사용자가 휴대폰 접속·로그인과 녹음 파일 재생을 확인했다. 다운로드가 `.bin`으로 고정되는 문제를 `.webm`/`.ogg` 응답으로 수정하고 녹음 관련 19개 시험(실패/오류 0, Windows 링크 skip 2)을 완료했다. 저장 원본은 변경하지 않았으며 운영 API 이미지 재빌드·재다운로드 확인은 남아 있다. 유료 호출 없음.

추가 연결 준비: Deepgram final의 화자별 원문 보존·세션별 event ID·offset 보정·다화자 일괄 저장과 승인 keyterm 전달을 구현했다. loopback 전용 PCM 세션에서 DB 작업을 분리하고 시간/전송량·예산 제한 및 종료 시 비용 처리를 연결했다. OpenAI는 외부 호출 중 DB 잠금을 유지하지 않고 응답 usage 정산 후 근거·revision·승인 용어를 검증해 요약/검토 대기 교정을 저장한다. 시간 초과·취소·불확실 청구도 시험한다. 모두 운영 경로에 연결하지 않은 준비 코드이며 실제 POC·장시간 처리의 완료로 계산하지 않는다.

2026-10-21 연결 준비 보강: 회의별 활성 STT 세션 단일화·재연결 offset 검증·Metadata 요청 ID 기록, 정리 실패 시 원장/세션 독립 종료를 구현했다. 저장 timeout에서는 실제 worker 종료까지 claim을 유지한다. 선택적인 PostgreSQL 시작 복구는 프로세스 수명의 advisory lock 아래 남은 예약을 해제하고 전송 요청을 UNCERTAIN으로 보존한다. 기본 앱은 여전히 MOCK/LOCAL_RECORDING이다.

독립 구조 재검토는 기존 차단 2건 해결 후 WATCH, 코드·보안 검토는 제한 범위 COMMENT이며 전체 승인으로 계산하지 않는다. 이전 stream 감사 기록 정리는 회귀 시험 후 보강했다. 새 POC 명령의 리뷰 지적 3건은 재현 시험 후 수정하고 해당 범위 재검토를 마쳤다. 운영 활성화 전 잠금 연결 유실 보호와 실제 공급자 취소 경로 검증은 남아 있다. 최신 시험 결과와 검토 공백은 [07](07-TEST-AND-EVAL.md)에 기록한다.

2026-10-21 별도 [유료 POC 실행 명령](../scripts/README.md#bounded-provider-poc)을 추가했다. 기본 dry run은 키 조회·외부 호출 없이 동작하며 실제 실행은 합성 자료 승인·명시적 opt-in·요청별 시간/금액 상한을 요구한다. 패키징된 JAR로 양쪽 dry run과 가짜 공급자 시험을 통과했다. 실험 결과는 자동 GO 판정이 아니며, 실제 한국어 참조 음성·사람 정렬 평가가 필요하다. 현재 에이전트 환경에서 두 API 호스트의 443 연결이 불가해 실제 실행은 하지 않았다. 앱의 월 예산 원장과 별도인 명령이므로 여러 비교 실험의 승인 총액을 나눠 관리해야 한다.

사용자가 일반 PowerShell에서 GitHub `Iusto/meeting-note` 푸시 완료를 확인했다. 에이전트 실행 환경의 네트워크 제한과 연결 앱의 쓰기 권한 오류는 별개로 유지된다. 유료 POC나 배포 이미지 변경은 실행하지 않았다.

### NO-GO 조건
- 실측 한국어 전사 정확도가 개인 실사용 수준에 현저히 미달.
- 화자 구분이 빈번히 뒤바뀌는데 보완/사용자 수정 UX로 감당하기 어려움.
- 비용 제한이 적용되지 않거나 무한 재시도 위험.
