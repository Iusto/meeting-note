# 01. PRD — 개인용 AI 회의록 요구사항

**개인 실사용·개발 학습 중심.** 아래는 제품의 요구사항과 목표이며 구현 완료 목록은 아니다. 현재 상태는 [개발 계획](08-IMPLEMENTATION-PLAN.md), 검증 근거는 [테스트·검증](07-TEST-AND-EVAL.md)을 따른다.

## 목적·비목적
- 목적: 한국어 회의의 **실시간 대화록**과 **화자 라벨**을 보여주고, MES·ERP·IT 용어를 문맥에 맞게 보정, 종료 후 요약·결정사항·후속업무 생성.
- 사용자: 1인 소유 계정. 집 PC는 웹·API·DB·파일 서버 역할; RTX 3060 Ti로 실시간 로컬 AI 추론하지 않음.
- 규모: 주 3회 × 회당 3~4시간 = 4주 36~48시간; **월 60시간은 비용·부하 스트레스 시나리오**, 확정 사용량 아님.
- 비목적: SaaS 출시·가격 경쟁·구독/결제·다중 조직·팀원 계정·실명 자동 식별·완벽한 동시 발언 분리·화상회의 봇.

## UX 규칙
- 사용자는 교정을 기다리지 않고 자막을 본다. 상태: `PARTIAL`, `FINAL`, `CORRECTED`, `REVIEW_REQUIRED`.
- 화자 상태는 텍스트 상태와 독립: `UNKNOWN`, `TENTATIVE`, `CONFIRMED`, `OVERLAP`.
- 말더듬은 보기 좋게 정리하되 발언 정정(금요일 → 목요일)은 보존한다.
- 원문과 교정문 모두 확인할 수 있으며, AI는 사용자가 최종 수정한 발언을 덮어쓰지 못한다.

## 통합 검증의 품질 목표 (달성 여부 미검증)
- 실시간 첫 자막 지연 p95 ≤ 3초; 확정 지연/통신 장애/재연결도 측정.
- 사용자 체감 가능한 화자 분리·한국어 MES 용어 인식; 임계치 설정 전 샘플 구축 필수.
- 4시간 테스트에서 **녹음 유실 0건**, 전사 누락/화자 오인식은 건수와 재검토율 기록.
- 개인 비용은 예산 가드로 제한; 월 60시간 풀 기능 사용은 예산 초과 가능성이 있음을 UI에 명시.

## 범위 밖
정액제, 서비스 결제, 결제 프로바이더, 관리자 조직 관리, 다중 테넌트, 초대·사용자별 권한, 대규모 관측 시스템, RAG/벡터 DB, 로컬 AI 자동 모델 라우팅, Zoom/Teams 회의 자동 참가.
