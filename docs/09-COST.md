# 09. 개인 API 비용·예산 정책

**아래 단가는 2026-10-21 확인 기록이며 이번 문서 정리에서 재조회하지 않았다.** USD 기준, 세금·환율·재요청·네트워크/서버 비용 별도다. 당시 Deepgram 가격은 프로모션을 포함하며 변동 가능하다. 실제 실행 전 [공식 출처](references/12-OFFICIAL-REFERENCES.md)에서 재확인하고 가격 버전을 남긴다. 실제 청구서가 최종 근거이며 아래 표로 자동 과금하지 않는다.

## 실제 통합 테스트의 예산

ADR-021에 따라 사용자가 웹앱의 실제 AI 경로를 실사용으로 검증한다. 앱 월 예산의 초기값은 `0 USD`이며, 사용 전 **사용량·예산**에서 양수로 저장한다. 처음에는 `3 USD`처럼 작은 값이 적합하다. 이 값은 STT와 OpenAI 교정·요약·용어 후보, 재연결·재요청의 누적 상한이며 요청마다 새로 부여하지 않는다.

가짜 공급자 통합 시험은 비용 0으로 먼저 수행한다. 실제 호출은 승인된 자료·명시적 opt-in·시간 제한·총금액 제한을 적용하고, 예산 또는 시간 소진 시 추가 호출을 중단한다. 앱 추정액과 공급자 확정 청구액은 구분한다.

|---|---:|---:|---:|
| 36시간 | 2,160 | $17.50 | $23.76 |

KRW로 보려면 **결제일 환율**을 적용한다. 예시 환율 1달러=1,350원이라면 60시간 프로모션 전체 기능 STT 약 39,366원, 정상가 시 약 53,460원. 국내 부가세 등 별도.

## OpenAI `gpt-6.1-sol` (Standard)
- 공식 문서: 입력 $2/100만 토큰, 출력 $10/100만 토큰(캐시/별도 티어 제외).
- **요약 가정:** 매 1시간에 입력 20,000/출력 2,000 토큰 × 60h → `1.2M × $2 + 0.12M × $10 = $3.60`.
- **선택적 교정 가정:** 매 1시간에 입력 10,000/출력 1,000 토큰 × 60h → `$1.80`.
- 위 가정 합산 **STT $29.16 + LLM $5.40 = $34.56** (예시 환율 약 46,656원), 세금/재전사/재요약/서버 제외.
- 교정이 길어지거나 전체 전사를 매번 재출력하면 비용 증가. **이는 실제 측정이 아닌 시뮬레이션**.

## 예산 가드
- API 호출 없이 가정을 바꿔 계산하려면 [오프라인 비용 계산기](../scripts/README.md#monthly-cost-scenarios)를 사용한다. 예제 단가는 합성 값이며 실제 가격이 아니다. 단가·토큰 가정·가격 버전을 입력하면 36/48/60시간의 STT/LLM 비용과 예산 초과를 출력한다.
- 개발 기본: 외부 API 연결 **OFF**. 실비 테스트는 분 단위 제한/자격 증명 opt-in.
- 현재 DB 설정: `monthly_budget_usd`(초기 0 USD), `warn_at_percent`(80%), `per_meeting_max_minutes`(240분), `recording_retention_days`(자동 삭제 없음). 앱의 유료 실행 플래그는 DB 필드가 아니라 `PAID_API_TESTS_ENABLED` 환경변수다. 비공개 배포 스크립트는 `-EnablePaidAi`를 명시해야 이를 켠다.
- 초기 월 상한 **3만 원 상당**은 과거의 권고안이다. 실제 통합 테스트의 사용량을 본 뒤 사용자가 월 예산을 정한다.
- **주의:** 3만 원 월 한도라면 Nova-3 full옵션으로 월 60시간을 처리할 수 없다. 시간·옵션·상한 중 하나는 조정해야 한다.
- 신규 실비 작업 시작 전 잔여 예산/회당 예상 원가 표시. 예산 소진 시 STT 신규 연결 방지·로컬 녹음 유지.
- 공급자별 실제 사용량과 청구액은 소액 오차가 있을 수 있으므로 **앱 추정 원가는 과금 확정이 아님**.
- $200 신규 크레딧 등 프로모션은 정책/자격에 따라 변동되므로 예산에 선반영하지 않는다.

## 구현된 내부 가드
- `RESERVED → DISPATCHED → SETTLED/UNCERTAIN`; 전송 전 예약만 `RELEASED`로 해제한다. 호출자는 기존 트랜잭션 밖에서 원장 변경을 시작해야 하며, 전송 선점 커밋 이후에만 외부 요청을 보낸다. 같은 요청 ID는 다시 전송할 수 없다.
- 설정 행 잠금으로 예약·정산·청구 대조·예산 변경을 직렬화한다. 예산 0/잔액 부족, 지난 UTC 월의 미전송 예약, 축소된 요청 시간 상한을 검사한다. 재연결 STT와 여러 OpenAI 요청도 회의당 최대 금액·시간에 누적한다. 회의·주제를 삭제해도 비용 기록을 지우지 않는다.
- 미완료·과금 미확인은 예약액을 유지한다. 응답이 유실돼도 청구 근거로 실비를 기록할 수 있으며, 사용량은 임의로 채우지 않는다. 미완료는 예약액·실비 중 큰 금액, 정산 후에는 추정액·실비 중 큰 금액을 예산에 반영한다. 초과 사실은 저장하고 다음 예약을 막는다. 청구 미확인은 `null`로 표시한다.
- USD는 소수 6자리, 예약은 올림한다. 설정한 단가와 가격 버전으로 공급자 전송 전에 보수적으로 예약한다. 기본 서버 시간 상한은 회의당 4시간이며, 회의당 금액은 DB 설정(초기값 3 USD)을 사용한다. DB의 회의 시간 상한과 잔여 예산이 더 작으면 그 값을 따른다.
- 원장의 금액은 공급자 청구서가 아니라 사전 예약·응답 usage 기반 추정치다. 실제 청구 대조와 장시간 강제 종료는 실사용에서 검증한다.

## 절감 우선순위
1. 실시간 전사를 전체 파일 STT로 **다시 전량 처리하지 말기**.
2. 회의 종료 후 요약 1회 기본, 수정 시 명시적 재요청.
3. 주제 사전은 캐시, 확정 발언만 LLM 선택적 교정.
4. 재검증은 특정 중요 구간만; 품질이 증명된 뒤 최적화.
5. 회의 기록은 녹음 시간·실과금·LLM 토큰을 분리 집계.

공식 가격: https://deepgram.com/pricing ; https://developers.openai.com/api/docs/models/gpt-6.1-sol

## 회의당 금액 변경 (2026-10-29)

월 예산과 회의당 최대 예산은 별도 설정이다. **사용량·예산 → 회의당 최대 예산 (USD)**에서 0.01~10000 USD로 저장한다. 초기값은 3 USD이며 월 예산·기존 예약 잔액이 더 작으면 그 한도를 따른다. 새 STT 세션과 새 LLM 작업부터 적용하며 이미 진행 중인 공급자 작업의 예약은 바꾸지 않는다. 실제 앱의 회의당 금액은 DB 설정을 사용한다.
